# Social Media Content Automation Workflow using n8n

🚀 This project automates social media content posting using [n8n](https://n8n.io/).

## 📋 Features
- Automatically schedule and post content to platforms like Twitter, LinkedIn, etc.
- Pulls content from a Google Sheet or RSS feed
- Allows easy configuration of posting times and messages
  
## ⚙ Tech Stack
- n8n automation tool
- Google Sheets / APIs
- HTTP request integrations

## 🚀 How to Use
1. Import workflow.n8n.json into your n8n instance.
2. Configure credentials (e.g., Twitter API key).
3. Set up content sources and posting schedules.
